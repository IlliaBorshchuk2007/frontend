# Лабораторна робота №1 — Веброзробка

Проста навчальна сторінка з адаптивним оформленням і перемикачем світлої та темної теми.

## Файли проєкту

- `index.html` — структура сторінки: заголовок, текст, кнопка, інформаційний блок і футер.
- `styles.css` — кольори, розміри, оформлення для комп’ютера та телефона.
- `script.js` — обробник натискання кнопки «Темна тема».
- `README.md` — опис проєкту та інструкція запуску.

## Локальний запуск

1. Відкрити цю папку `lab1` у VS Code через **File → Open Folder**.
2. Установити розширення **Live Preview** від Microsoft.
3. Відкрити `index.html`, натиснути **Ctrl+Shift+P** і виконати команду **Live Preview: Show Preview**.

Для швидкого перегляду також можна відкрити `index.html` у звичайному браузері.
Для виконання лабораторної використовуємо локальний сервер Live Preview.

## Як перевірити

1. Переконатися, що видно заголовок, текст, три інформаційні блоки та футер.
2. Натиснути «Темна тема»: кольори та повідомлення під кнопкою мають змінитися.
3. Натиснути повторно: має повернутися світла тема.
4. Перейти до кнопки клавішею **Tab** та активувати її клавішею **Enter** або **Пробіл**.
5. Звузити вікно браузера: блоки HTML, CSS і JavaScript мають розташуватися в одну колонку.
